# Description normalizer: runnable adaptation

Python 3.10+, standard library only. Run from the repository root:

```bash
python3 -m unittest discover -s samples/description-normalizer -v
python3 benchmarks/description-quality/run.py
```

The [article](../../investigations/cleaning-job-descriptions.md) explains the decisions and known losses. The [evaluation](../../benchmarks/description-quality/README.md) includes inputs, expectations, results, and a baseline.

## Scope and provenance

`normalizer.py` is an AI-assisted Python adaptation of the plain-text normalization and summary path from YachtPass's `OpportunityDescriptionNormalizer.cs`. The reviewed source blob was `02f583a3d0b15fec7ee5b6e3ada65f9358ea0ede`. The production repository remains private; this sample does not require access to it.

The adaptation retains the order of regex operations, metadata removal, line filtering, and truncation behavior, including known failures. It omits production DTOs, structured-section JSON processing, application services, and storage. Python and .NET regex, entity decoding, Unicode indexing, and whitespace behavior can differ. This is not a verified cross-runtime parity port. The production C# implementation was not executed during this evaluation.

The synthetic fixtures, Python tests, evaluator, and articles were created with AI assistance for this portfolio. Results were generated by running the published Python code; they are not historical production measurements. The sample must not be presented as independently authored research without disclosing that assistance.

## Boundaries

Treat output as plain text and escape it at rendering time. Do not use this regex pipeline to make untrusted HTML safe. The sample is synchronous, unbounded with respect to input size before processing, and has no regex timeout; it is not a hardened public service.

The summary limit is a target, not a strict maximum in every branch: the original word-boundary fallback appends `...` after selecting a prefix. An input without a usable boundary can become just `...`. The separate `IsMeaningfulVacancyContent` heuristic from production is outside this sample.
